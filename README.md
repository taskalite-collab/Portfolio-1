# Portfolio Website UI Exercise

A multi-page portfolio-style interface built with HTML and CSS. It includes Home, Services, Projects, Clients, and Contact pages.

## Run

Open `index.html` in a browser and use the navigation links.

Some sections still contain template copy, sample project labels, and placeholder client content. Replace those with accurate personal work before presenting this as a finished professional portfolio. The contact form is a visual mockup and does not send messages.
